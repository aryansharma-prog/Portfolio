CortexAI is a multi-agent AI platform designed to intelligently orchestrate specialized AI agents for different types of tasks while optimizing token utilization. Rather than relying on monolithic prompt contexts or wasteful single-model inference, CortexAI partitions queries recursively and delegates them to task-specific agents using LangGraph state graphs.

export const routeToOptimalModel = (state: AgentState) => {
  if (state.complexity < 0.4 && state.tokenBudget < 2000) {
    // Fast inference for classification & lightweight queries
    return invokeGroqLlama(state.subtasks);
  }
  // Deep multimodal reasoning & multi-source synthesis
  return invokeGeminiPro(state.subtasks, {
    context: state.sharedContext,
    temperature: 0.2
  });
};

export const decomposeTask = async (prompt: string): Promise<SubTask[]> => {
  const plan = await plannerAgent.generatePlan({
    query: prompt,
    maxDepth: 3,
    allowParallelExecution: true
  });

  return plan.subtasks.map((subtask) => ({
    ...subtask,
    assignedAgent: resolveSpecialist(subtask.domain)
  }));
};
// Self-Evaluating Critic Agent Verification Loop
export const evaluateTrustScore = async (output: AgentOutput): Promise<VerificationResult> => {
  const critique = await criticAgent.verify({
    claims: output.claims,
    citations: output.retrievedSources,
    codeExecutionPass: output.testSuiteResult
  });

  return {
    isApproved: critique.score >= 0.85,
    confidence: critique.score,
    feedback: critique.recommendations
  };
};

Technical Deep Dive

CortexAI — Multi-Agent System Architecture

1. Problem Statement & Motivation

Standard Large Language Model implementations suffer from severe latency degradation, hallucination risks on multifaceted tasks, and high token costs when processing long contexts with monolithic prompts. CortexAI solves this by implementing a specialized, asynchronous multi-agent orchestration architecture that partitions user goals into domain-specific subtasks.

2. Evaluation Benchmark & Results

50 Question Set Coding, Research, Math, Strategy, Reasoning
100% Success Reliable end-to-end execution
~40% Saved Optimized prompt token usage

3. Architectural Pipeline

01
Task Decomposition Router

Analyzes user query and creates a stateful execution plan using LangGraph DAGs.

02
Adaptive Model Switching

High-speed reasoning via Groq for initial routing; Gemini 1.5 Pro for deep multimodal and coding synthesis.

03
Hybrid Vector Retrieval & Shared Memory

Pinecone for dense semantic search + Redis for agent-to-agent shared short-term execution memory.

04
Self-Evaluating Verification Loop

Dedicated critic node cross-validates citations and code execution before returning verified results.

4. Technology Implementation

Orchestration LangGraph, LangChain, Node.js
Model Providers Google Gemini API, Groq Cloud
Memory & Vector Stores Pinecone, Redis, MongoDB
Frontend & Visualization React, Modern CSS, WebSockets
