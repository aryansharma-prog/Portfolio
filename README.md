# Aryan Sharma Portfolio

A modern portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive portfolio layout
- Dark/light theme toggle
- Project showcase
- Skills and education sections
- Contact section
- Live coding profile stats

## Run locally

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

## Project structure

```text
portfolio/
├── index.html
├── styles.css
├── script.js
├── package.json
├── .gitignore
├── README.md
└── assets/
```

## Deploy
You can deploy this project using GitHub Pages, Netlify, or Vercel.

## GitHub push workflow

```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin <your-github-repo-url>
git push -u origin main
```
